# Francis Vernard Yap — Developer Portfolio

Personal developer portfolio showcasing full-stack web applications, database systems, and technical projects.

Built with a dark IDE-inspired aesthetic, featuring a reactive 3D profile card, interactive project showcases, and a direct contact form.

## Tech Stack

- React 19 + TypeScript + Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Development

```bash
npm install
npm run dev
npm run build
```
